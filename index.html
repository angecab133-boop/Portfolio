Web app | Ride booking | HTML / CSS / JavaScript

GoRide

GoRide is a ride-booking app made for Baguio City. A passenger signs up, picks a pick-up spot and a place to go, and chooses a motorcycle, car or van. The price shows before booking. The ride can start now or be set for later. The passenger can watch the driver on a map, call or message the driver, and rate the ride. A driver can sign up too, go online, accept ride requests and see how much money was earned. This is a practice app, so the driver and the map are not real.
